# Tax Management & Analysis System

A portfolio project built with Excel, Office Scripts, and TypeScript.

The solution automates tax calculations, validation, reporting, and dashboard generation while following enterprise-style design principles.

## Features
- Tax calculation engine
- Dynamic tax brackets
- Data validation
- Audit logging
- Executive reporting
- Dashboard KPIs
- Interactive charts
- Modular Office Scripts
- Power Automate ready

## Office Scripts
| Script | Purpose |
|----------|----------|
| CalculateTaxes | Calculates taxable income and tax due |
| ValidateData | Detects data quality issues |
| GenerateReports | Produces management summaries |
| GenerateTopTaxpayers | Ranks taxpayers by tax due |
| RefreshDashboard | Updates KPI cards |
| CreateDashboardCharts | Creates dashboard charts |

- Microsoft Excel
- Office Scripts
- TypeScript
- Power Automate (future integration)
